# Test Plan — Innovation Platform (Post-Migration)

**Prerequisites for this entire plan:** `prisma migrate deploy`, `prisma generate`, and `prisma db seed` have been run successfully on the target environment, and `npm run typecheck` / `npm run lint` both report 0 errors against the regenerated client.

**Test accounts needed:** at least one user per role — `SYSTEM_ADMIN`, `INTERNAL_EDITOR` (with a department assignment), `EXTERNAL_PARTNER` (shared on at least one solution/agreement), `VIEWER`. For department-scoped tests, at least two `INTERNAL_EDITOR` accounts in *different* departments are needed to verify scope isolation.

Priority legend: **Critical** = blocks Beta if broken · **High** = must fix before Beta, workaround possible · **Medium** = should fix soon after Beta · **Low** = polish.
